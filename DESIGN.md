# Anton CGI Design Context

## Direction

Sparse identity, flagship polish. The index is a brand/portfolio surface with a restrained dark scene, local typography, procedural motion, and project links that feel deliberate and easy to scan.

## Color

Use tinted dark neutrals instead of pure black or pure white. Prefer OKLCH for CSS color tokens. The homepage background should sit near a blue-green black, with soft off-white text, muted blue-gray secondary text, and a small mint focus/accent role for keyboard state and selection.

## Typography

Use local Satoshi from `assets/fonts` for the index surface. Keep the type system quiet and precise, with weight and scale doing the hierarchy. Letter spacing should stay at `0` for polished readability.

## Layout

The homepage should remain compact and centered, but not template-centered. Use a narrow reading column, deliberate vertical rhythm, project groups with clear link affordances, and mobile behavior that avoids crowded fixed metadata.

## Motion

Keep the flow-field as the primary motion. Entrance and hover transitions should be subtle, transform/opacity based, and disabled for reduced-motion users.
